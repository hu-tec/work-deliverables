# db-document-organization - Design Document

> Version: 1.0.0 | Date: 2026-05-26 | Status: Approved
> Plan: `docs/01-plan/features/db-document-organization.plan.md`

## 1. Overview

Python 표준 라이브러리만 사용하는 생성 스크립트가 원본 CSV 9개를 읽고
`일반사용자용_정리DB` 아래에 설명 문서와 주제별 CSV를 출력한다. 입력은
UTF-8 BOM CSV로 읽으며, 출력 CSV 역시 Excel 호환을 위해 UTF-8 BOM을 사용한다.

## 2. Output Structure

| 폴더 | 이용 목적 | 주요 출력 |
|------|-----------|----------|
| `01_분류체계` | 제공 영역과 자격 급수 파악 | 서비스 분야, 급수 목록 |
| `02_시험운영` | 시험 구성과 평가 방식 확인 | 선택항목, 문항/채점, 일정 |
| `03_교육자료` | 학습 콘텐츠와 커리큘럼 확인 | 프롬프트/번역/윤리 교재, 커리 자료 |
| `04_문제은행` | 시험 문제와 답안 열람 | 대분류별 문제은행 CSV |
| `05_서비스기획` | 서비스·결제·통합 항목 검토 | 통합 항목 사전, 운영 아이디어 |
| `_생성도구` | 동일 결과 재생성 | Python 스크립트 |

## 3. Transform Rules

### 3.1 Common Rules

- 입력 파일은 변경하지 않는다.
- 출력 레코드는 `원본파일`과 가능한 경우 `원본행`을 포함한다.
- 빈 행과 표 장식 문구는 데이터 목록에서 제외한다.
- 원본의 맞춤법, 물음표, 미확정 표기는 원문 보존을 위해 수정하지 않는다.

### 3.2 Source Mapping

| 입력 | 변환 방식 |
|------|----------|
| `분야.csv` | 분야 대/중/소 및 자격 급수 열을 별도 목록으로 추출 |
| `대표 DB-시험정보.csv` | 각 열의 고유 선택값을 설정항목/선택값 목록으로 변환 |
| `대표DB.csv` | 출제·채점, 일정, 서비스/결제 구간을 읽기 쉬운 구간 문서로 변환 |
| `문제와 채점지.csv` | 응시 급수와 문항 구성 자료 추출 |
| `교재.csv` | 병렬 배치된 프롬프트/AI윤리/AI번역 교재 열을 각각 추출 |
| `커리.csv`, `커리 급수별 (프롬).csv` | 주제별 원문 내용을 읽기용 Markdown으로 분리 |
| `문제은행.csv` | 47개 본문 행을 대분류별 CSV로 분리, 미배정 아이디어 별도 추출 |
| `통합사본.csv` | 원본 열별 항목명과 기재 예시를 데이터 사전으로 재구성 |

## 4. Verification

- 입력 문제은행의 본문 행 수와 분리 출력 행 수가 일치해야 한다.
- 출력 폴더의 CSV가 다시 파싱 가능해야 한다.
- 안내 문서가 출력 파일 목록과 원본 대응 관계를 제시해야 한다.

## 5. Implementation Order

1. 공통 CSV 읽기/쓰기 및 Markdown 생성 함수 구현
2. 분야, 시험, 교육자료, 문제은행, 서비스기획 변환 구현
3. 안내 문서와 검증 결과 생성
4. 스크립트 실행 후 산출물 수량·행 수 확인
