AI 분석 삽입 위치

시험접수 목록: AI 제공 여부 시험접수 팝업: 분석 샘플 요금제: 등급 비교 장바구니: 선택 상품 요약 제출확인: 분석 예정 안내 시험결과 목록: 리포트 보기

관리자
관리자 홈: 분석 실패/대기 현황 시험관리: AI 옵션 설정 결제관리: 분석 상품 필터 통계: 구매율/완료율/실패율

1차 MVP

  • 시험 접수 결제
  • AI 분석 상품 결제 연결
  • 결제 완료/실패/미승인 상태 처리
  • 결과 화면 리포트 보기
  • 관리자 결제 필터

2차 확장

  • 결과 화면 분석 업그레이드 구매
  • 환불/부분취소
  • 전문가 검증 정산
  • 채점자 AI 참고 패널
  • 분석 실패 재시도

남은 결정

  • 기본 분석 무료 제공 여부
  • 포인트의 현금성 여부
  • 미승인 결제 시 응시권 부여 기준
  • 전문가 검증비 정산 기준
  • 분석 실패 시 환불 정책
v0.3 제안의 핵심은 AI 분석을 별도 기능으로 분리하지 않고, 기존 2024 흐름의 접수, 결제, 제출, 결과, 채점, 관리자 운영 화면에 자연스럽게 삽입하는 것입니다. 사용자는 상품 가치를 구매 전에 이해하고, 운영자는 결제/분석/검증 상태를 한 흐름으로 추적할 수 있어야 합니다.
