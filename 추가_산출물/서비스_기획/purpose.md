# VibeCoding 기획정의

## 시험 솔루션
### 24년
24년 버전의 경우, 아래의 프로세스들을 모두 포함할 수 있는 기능이 정의도어있다. 
  - 시험 전체 프로세스
  - 번역 전체 프로세스
  - 통독 전체 프로세스


### 25년
25년 버전의 경우, UX/UI개선이 목적이 되었다.

- 관리자 페이지, 전문가 등록페이지 분리
- 홈페이지 10개 생성시 공통으로 쓸만한 것들을 분리
- *다른 홈페이지를 만들때도 UX/UI를 사용.*


### 26년 : vibe
26년에 AI를 이용한 시험문제, 전문가, 번역 퀄리티의 AI 분석추가되었다.
현재 24년 기준으로 하였을 때, 어느 프로세스에 AI분석을 삽입할지 제안이 필요하다.

- 가격
  - 109개 언어 (12000개정도의 경우의 수)
  - 대분류 : 프롬프트, 번역
  - 중분류 : 산업, 영역 기능
  
  위와 같이 여러 언어, 대분류, 중분류등 여러 분류에 따른 가격정책(Tier)이  정리되어있음.

이 가격설정에 대한 내용도 24년에 어디에 붙여서 제공하는게 좋을지 제안이 필요하다.

Ai분석 기능은 다음과 같다.
#### 대상

- 대학생
    - 목적성글(예: 고소장)을 주고, AI 프롬프트 작성능력 평가
- 일반인
    - 목적성글과 AI가 도출해준 글을 함께 보여주며, 어떻게 더 잘 쓸수 있을지 답변하도록 하고 평가
- 전문가
    - 전문가는 순수 답지를 보여주고, 직접 평가

오프라인 환경을 고려하여, 인쇄 기능도 필요.


### 관리자 페이지 레이아웃 구성
복잡한 데이터를 한눈에 보기좋게 필터링 할 것인지 고민이 필요함.
- 뱃지, 칩, 이모지등을 활용하여 한눈에 구분할 수 있도록 해야 함. 
- 기반 데이터는 excel형태로 제공할것이며, 이를 토대로 레이아웃 구성 및 구성 방향에 대한 md파일을 생성
