# 파일 추출 + 업무 프롬프트 생성기 기획안

## 1. 전체 개념

이 생성기는 단순히 프롬프트 문장만 만드는 도구가 아니라,  
**파일을 먼저 찾고 → 관련 자료를 고르고 → 업무 목적에 맞는 프롬프트를 생성하는 도구**입니다.

사용 흐름은 아래 5단계로 구성합니다.

| 단계 | 화면 이름 | 핵심 역할 |
|---|---|---|
| 1 | 파일 찾기 | 키워드, 하위분류, 확장자, 최신본 기준으로 관련 파일 추출 |
| 2 | 업무 프롬프트 만들기 | 사업계획서, 자격증, 교육과정, 법무, 업무정리 중 선택 |
| 3 | 1차 구조 설계 | 완성본 전 단계, 큰 틀과 구조 설계 |
| 4 | 2차 UX 개선 | 화면 흐름, 입력칸, 체크박스, 배치 개선 |
| 5 | 최종 산출물 | 표, 보고서, 메일, Word 문서, HTML 등으로 출력 |

---

```text
├──────────────────────────────────────────────────────────────────────────────┤
│ 프롬프트 단계                                                                  │

│                                                                              │

│ 너는 [ 선택한 업무 분야 ] 전문가야.                                            │
└──────────────────────────────────────────────────────────────────────────────┘
```

# STEP 1. 관련 파일 찾기

프롬프트 생성 전에 먼저 관련 파일을 찾는 영역입니다.  
파일을 못 찾으면 이후 프롬프트 품질도 떨어지기 때문에, 이 영역이 가장 먼저 나와야 합니다.

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│  STEP 1. 관련 파일 찾기                                                        │
├──────────────────────────────────────────────────────────────────────────────┤
│ 폴더 설정                                                                      │
│ ┌──────────────────────────────┬───────────────────────────────────────────┐ │
│ │ 원본 폴더                    │ [ D:\회사자료\정부사업\ ] [찾기]         │ │
│ │ 결과 저장 폴더               │ [ C:\Desktop\추출파일\ ] [찾기]          │ │
│ └──────────────────────────────┴───────────────────────────────────────────┘ │
│                                                                              │
│ 파일 조건                                                                      │
│ ┌───────────────┬───────────────┬───────────────┬─────────────────────────┐ │
│ │ 확장자        │ 기간          │ 버전 기준     │ 파일명 기준             │ │
│ │ ☑ docx ☑ pdf  │ 최근 1년      │ ☑ 최종본 우선 │ ☑ 접두어 포함           │ │
│ │ ☑ xlsx ☑ pptx │ 전체 기간     │ ☐ 초안 포함   │ ☐ 날짜 포함             │ │
│ └───────────────┴───────────────┴───────────────┴─────────────────────────┘ │
│                                                                              │
│ 자료 분류                                                                      │
│ ┌───────────────┬────────────────────┬────────────────────────────────────┐ │
│ │ 대분류        │ 중분류             │ 소분류                             │ │
│ │ 정부사업      │ 사업계획서          │ 시장조사 / 예산 / 경쟁사 / 로드맵 │ │
│ │ 자격증        │ 운영규정            │ 변경신청 / 반려 / 검정기준        │ │
│ │ 교육과정      │ 커리큘럼            │ 차시표 / 모집안내 / 제안서        │ │
│ │ 법무          │ 증빙자료            │ 계약 / 증거 / 손해액 / 메일       │ │
│ │ 업무관리      │ 지시사항            │ 대표님 / 이사님 / 직원 / 거래처   │ │
│ └───────────────┴────────────────────┴────────────────────────────────────┘ │
│                                                                              │
│ 검색 키워드                                                                    │
│ ┌──────────────────────────────┬───────────────────────────────────────────┐ │
│ │ 반드시 포함할 키워드         │ [ 사업계획서, 시장조사, 수익모델 ]        │ │
│ │ 관련성 강화 키워드           │ [ AI교육, 문제생성, 평가플랫폼, 학원 ]   │ │
│ │ 보류/검토 키워드             │ [ 초안, 예전안, 반려, 미확정, 참고용 ]   │ │
│ │ 제외 키워드                  │ [ 폐기, 사용안함, 삭제, 구버전 ]         │ │
│ └──────────────────────────────┴───────────────────────────────────────────┘ │
│                                                                              │
│ 파일 찾기 옵션                                                                 │
│ ☑ 최신 파일 우선      ☑ 최종본 우선      ☑ 비슷한 파일도 같이 찾기             │
│ ☑ 제목/본문 둘 다 검색 ☑ 표/이미지 포함 파일 표시 ☑ 관련도 점수 표시          │
│                                                                              │
│ [ 관련 파일 찾기 ] [ 찾은 파일 미리보기 ] [ 선택 파일만 프롬프트에 반영 ]       │
```

## STEP 1 세부 항목

| 구분 | 항목 | 설명 |
|---|---|---|
| 폴더 설정 | 원본 폴더 | 검색할 파일이 들어 있는 폴더 |
| 폴더 설정 | 결과 저장 폴더 | 추출 파일이나 생성 프롬프트 저장 위치 |
| 파일 조건 | 확장자 | docx, pdf, xlsx, pptx, hwp 등 |
| 파일 조건 | 기간 | 전체 기간, 최근 1년, 최근 6개월 등 |
| 파일 조건 | 버전 기준 | 최종본 우선, 초안 포함, 반려안 포함 등 |
| 자료 분류 | 대/중/소 분류 | 정부사업, 자격증, 교육과정, 법무, 업무관리 등 |
| 검색 키워드 | 반드시 포함 | 꼭 들어가야 하는 핵심 단어 |
| 검색 키워드 | 관련성 강화 | 있으면 우선순위를 높일 단어 |
| 검색 키워드 | 보류/검토 | 참고는 하되 주의해야 할 파일 |
| 검색 키워드 | 제외 | 검색 결과에서 빼야 할 파일 |

# STEP 2. 업무 프롬프트 만들기

파일을 찾은 뒤, 찾은 파일을 기준으로 어떤 업무용 프롬프트를 만들지 선택합니다.

```text

│  STEP 2. 업무 프롬프트 만들기                                                  │
├──────────────────────────────────────────────────────────────────────────────┤
│ 작업 대상                                                                      │
│ ┌──────────────────────┬──────────────────────┬────────────────────────────┐ │
│ │ 받을 사람/대상       │ 말투                 │ 결과물 형태                │ │
│ │ [ 심사위원 ▼ ]       │ ☑ 전문적 ☑ 쉽게      │ ☑ 표 ☑ 문서 ☑ Word용       │ │
│ │ 대표님 / 이사님      │ ☑ 단정하게           │ ☐ 메일 ☐ HTML ☐ 보고서     │ │
│ │ 교수님 / 변호사      │ ☐ 강하게 요청        │                            │ │
│ └──────────────────────┴──────────────────────┴────────────────────────────┘ │
│                                                                              │
│ 내 멘션 / 두서없는 메모                                                        │
│ ┌──────────────────────────────────────────────────────────────────────────┐ │
│ │ 지금 생각나는 말을 편하게 입력.                                             │ │
│ │ 예: 이사님이 갑자기 시킨 일인데 뭐부터 해야 할지 모르겠어.                  │ │
│ │ 예: 시장성과 수익성을 그래프/도표로 보여줄 수 있게 지시문에 넣어줘.          │ │
│ └──────────────────────────────────────────────────────────────────────────┘ │
│                                                                              │
│ 정리 옵션                                                                      │
│ ☑ 두서없는 말 정리      ☑ 빠진 내용 질문      ☑ 중복 내용 삭제                │
│ ☑ 대/중/소 분류         ☑ 고정/준고정/선택 구분 ☑ 우선순위 표시               │

```

# 생성되는 프롬프트 공통 규칙

모든 생성기에서 생성되는 프롬프트는 아래 규칙을 따릅니다.

## 1. 첫 문장 고정

```text
너는 {선택한 분야} 전문가야.
```

예시:

| 생성기 | 첫 문장 |
|---|---|
| 사업계획서 | 너는 정부지원사업 사업계획서·시장조사 전문가야. |
| 자격증 규정 | 너는 민간자격 등록·운영규정 설계 전문가야. |
| 교육과정 | 너는 교육과정·커리큘럼·기관 제안서 기획 전문가야. |
| 법무증빙 | 너는 법무 증빙자료 정리·자문 요청서 작성 전문가야. |
| 업무정리/CEO Agent | 너는 CEO Agent 업무정리·우선순위 설계 전문가야. |

## 2. 입력하지 않은 항목은 자동 생략

1, 2, 3 형태로 모두 채우게 하지 않고,  
사용자가 입력한 항목만 프롬프트에 들어가도록 합니다.

## 3. `+추가` 방식 적용

아래 항목은 기본 1칸만 보이고 필요할 때만 늘립니다.

| 항목 | 방식 |
|---|---|
| 기본 지시사항 | 선택 입력 + 추가 |
| 고려사항 | 선택 입력 + 추가 |
| 가장 중요한 것 | 선택 입력 + 추가 |
| Must 기능 | 체크 + 추가 |
| Should 기능 | 체크 + 추가 |
| 보완 요청 | 선택 입력 + 추가 |
| 유지 요소 | 선택 입력 + 추가 |

## 4. 마지막 출력 지시 공통 포함

모든 프롬프트 마지막에는 아래 문구가 들어갑니다.

```text
마지막에는 표로 요약하고, Word 문서로 저장할 수 있도록 제목 구조를 포함해줘.
```
