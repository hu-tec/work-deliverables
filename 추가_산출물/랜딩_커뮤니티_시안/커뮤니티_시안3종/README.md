# 커뮤니티 / 공지 / 과정상세 리디자인 — 3가지 시안 제안

> 작성일 2026-05-29 · 대상: Times Education(타임스미디어) 랜딩
> 폴더: `community-redesign/` · 비교 허브: `community-redesign/index.html`

## 1. 배경 / 목표

세 개의 참고 화면을 한 사이트 안에서 일관된 구조로 구현한다.

| 영역 | 참고 | 핵심 |
|---|---|---|
| 커뮤니티 탭 구조 | hu-tec.github.io/TESOL/community | `공지 · FAQ · 후기 · 자료실` 4탭을 한 페이지 탭으로 운영 |
| 공지사항 게시판 | timestesol.com (news0) | `번호·분류·제목·작성자·등록일·조회` 테이블, 상단 공지 고정 |
| 과정 상세(콘텐츠 多) | hu-tec.github.io/ai-teacher/#/courses | 개요·소개·추천·특징·Before/After·커리큘럼·강사·FAQ·후기 |

**3가지 "디자인 방향"은 레이아웃·정보 밀도의 차이**이며,
색상·컴포넌트 토큰은 모두 **`design_system_major`(휴텍씨 디자인 시스템)** 를 따른다.

## 2. 공통 규칙 (design_system_major 준수)

레이아웃이 달라도 아래 토큰·컴포넌트 규칙은 3시안 공통이다.

- **브랜드 색** : primary `#0088ff` / strong `#006dcc` / 보조(전문가·CTA) `#822afd`
- **텍스트** : `#222 / #666 / #808080`, **배경** `#f8f9fc`(page) · `#fff`(base) · `#e7f2ff`(info-soft)
- **경계** : `#e3e5ed`(default) · `#cccccc`(strong)
- **Radius** : 기본 `0`(직각), **칩/상태 pill만 `20px`**
- **폰트** : `Noto Sans KR` 계열, `letter-spacing: -0.02em`
- **버튼** : `btn btn--primary | btn--outline | btn--secondary`, 크기 `btn--sm/md/lg`
- **접근성** : 명도 대비 ≥ 3:1, `aria-selected`(탭) · `aria-expanded`(FAQ), `:focus-visible` 유지, 상태는 색상만으로 구분하지 않음
- **공지 표** : 가로 스크롤 허용(모바일에서 억지 축소 금지), 헤더 12~13px / 본문 14px

## 3. 시안별 상세

### A. 정통 게시판형 (`design-a-classic/`)
- **콘셉트** : 격식·신뢰. 공공/교육기관 공식 게시판 톤.
- **탭** : 언더라인(`tabs--underline` 스타일)
- **공지** : `번호 · 분류 · 제목 · 작성자 · 등록일 · 조회` 풀컬럼, 상단 "공지" 고정 + NEW 표시, 페이지네이션
- **과정상세** : 다크 히어로 + sticky 서브내비 + **좌측 정보표(접수/기간/대상/수강료)** + 본문 블록(개요·소개·추천·특징·Before/After·주차별 표·강사·FAQ·후기)
- **적합** : 공지·행정 안내가 잦은 기관형 운영

### B. 모던 카드 + 사이드형 (`design-b-modern/`)
- **콘셉트** : 여백·패널 카드, 신청 전환 최적화.
- **탭** : pill
- **공지** : 미니멀 테이블 + 제목 아래 요약 한 줄 노출(스캔성↑)
- **과정상세** : 본문(과정소개·추천·특징·Before/After 2단·커리큘럼 카드·강사·FAQ·후기) + **우측 sticky 신청 패널**(수강료·기간·대상·신청 버튼)
- **적합** : 기수 모집·수강신청 **전환(CTA)** 중심

### C. 에디토리얼 / 매거진형 (`design-c-editorial/`)
- **콘셉트** : 큰 타이포·여백·룰(rule)로 읽는 맛. 브랜딩 강조.
- **탭** : 대형 텍스트 탭 + 더블 룰
- **공지** : hover 하이라이트 라인 테이블, 상세는 **드롭캡** 아티클
- **과정상세** : **좌측 목차(TOC) + 9개 섹션 롱폼 스크롤**(스크롤스파이로 현재 섹션 하이라이트)
- **적합** : 콘텐츠/스토리텔링·브랜드 인상 강조
- _주: 가독을 위한 큰 타이포는 유지하되, 폰트는 DS 정합을 위해 세리프 대신 Noto Sans KR 사용._

## 4. 폴더 구조

```
community-redesign/
├─ index.html              # 3시안 비교 허브
├─ README.md               # (본 문서)
├─ design-a-classic/
│   ├─ index.html          # 시안 홈
│   ├─ community.html      # 4탭(공지표·FAQ·후기·자료실)
│   ├─ notice-detail.html  # 공지 상세(이전/다음글)
│   ├─ courses.html        # 과정 목록
│   ├─ course-detail.html  # 과정 상세(리치)
│   ├─ styles.css          # DS 토큰 + A 레이아웃
│   └─ data.js             # 공지 7건·과정 4종 공통 데이터
├─ design-b-modern/        # (동일 파일 세트)
└─ design-c-editorial/     # (동일 파일 세트)
```

- `data.js` 는 3폴더 동일(공지 7건 + 과정 4종). 공지/과정 추가는 이 파일만 수정.
- 정적 HTML/CSS/JS만 사용 → 그대로 열거나 정적 호스팅 가능. 파라미터 `?id=` 로 상세 연결.

## 5. 보는 방법

1. `community-redesign/index.html` 을 브라우저로 연다. (비교 허브)
2. 시안 카드의 **홈 / 커뮤니티 / 과정상세** 버튼으로 흐름 확인.
3. 공지 제목 클릭 → 상세, 과정 카드 클릭 → 상세(`?id=ai-teacher` 등).

## 6. 다음 단계(선택)

- [ ] 한 시안 확정 → 실제 `site-template` 또는 운영 사이트에 반영
- [ ] 공지/과정 데이터를 관리자 CRUD(localStorage 또는 백엔드)와 연결
- [ ] 검색·페이지네이션 실제 동작 연결(현재는 표시용)
- [ ] 자료실 첨부파일 실제 다운로드 경로 연결
