# 입력폼 검색필터 컨트롤 기준

## 1. 대분류: 입력폼 기본

### 1.1 중분류: label과 입력은 한 덩어리

소분류:
- label은 짧게 쓴다.
- input, select, checkbox는 label과 가까이 둔다.
- 같은 맥락의 짧은 입력은 한 줄에 묶는다.

예시:

```text
기간 : 시작일 종료일 오늘 1주 1개월
성별 : 전체 M F
상태 : 전체 완료 대기 취소
```

### 1.2 중분류: 컨트롤 선택

소분류:
- 예/아니오: checkbox 또는 switch
- 하나만 선택: radio 또는 select
- 여러 개 선택: checkbox
- 날짜: date 또는 datetime-local
- 숫자: input number 또는 stepper
- 범위: slider 또는 시작/종료 input

## 2. 대분류: 검색 필터

### 2.1 중분류: 검색조건은 카드가 아니라 작업 도구

검색 영역을 큰 카드 여러 개로 나누지 않는다. 조건이 많아도 가능한 한 조밀한 한 영역 안에서 정리한다.

소분류:
- 조건명과 옵션을 한 줄로 붙인다.
- 짧은 옵션은 가로로 둔다.
- 그룹이 많으면 4단 또는 5단 grid를 쓴다.
- 검색어는 필터 태그 뒤 또는 옆에서 자연스럽게 늘어난다.

### 2.2 중분류: 제목과 옵션 한 줄

필수 예시:

```text
회원유형 : 전체 일반회원 정식회원 기업회원 전문가
성별 : 전체 M F
구독상태 : 전체 프리미엄 스탠다드 베이직 free
서비스유형 : 시험역 구독센터 시험사이트 통번문서 전시/행사
```

소분류:
- `회원유형`처럼 짧은 필터는 절대 세로로 길게 쌓지 않는다.
- 체크박스는 유지하되 label과 같은 줄에 둔다.
- 공간이 부족하면 옵션을 2열로 줄바꿈하되 그룹 전체 높이를 최소화한다.

### 2.3 중분류: 필터 태그

소분류:
- 선택된 필터 태그는 별도 행을 만들지 않는다.
- 검색어 앞쪽에 붙여 한 줄 안에서 흐르게 한다.
- 태그를 해제하면 검색어 영역이 앞으로 당겨진다.
- 태그가 너무 많으면 wrap을 허용하되 첫 화면 높이를 과도하게 늘리지 않는다.

## 3. 대분류: 날짜 입력

### 3.1 중분류: 날짜 선택

소분류:
- 입력 가능한 날짜는 달력 선택이 되게 한다.
- 납입일자, 회사입금일, 상담일, 다음예정일은 date/datetime 컨트롤을 쓴다.
- 테이블 안 날짜 입력도 클릭하면 picker가 떠야 한다.

### 3.2 중분류: 날짜 표기

소분류:
- 목록 표시는 짧게 한다.
- 상세 입력은 정확하게 입력 가능해야 한다.
- 날짜와 시간은 업무상 필요할 때만 함께 둔다.

## 4. 대분류: 버튼과 액션

### 4.1 중분류: 검색 버튼

소분류:
- 검색어 input 가까이에 둔다.
- 초기화는 검색 옆에 둔다.
- 필터 전체 해제는 태그 영역 끝 또는 검색 row 끝에 둔다.

### 4.2 중분류: 저장 버튼

소분류:
- 상세 패널 저장은 오른쪽 상단 또는 하단 action bar에 둔다.
- 위험 액션은 저장과 구분한다.

## 5. 요약표

| 항목 | 기준 |
|---|---|
| label/input | 가까이, 한 줄 우선 |
| 필터 옵션 | 제목 : 옵션들 가로 배치 |
| 필터 태그 | 검색어 앞 유동 배치 |
| 날짜 | picker 가능한 date/datetime |
| 검색 버튼 | 검색어 근처 |
| 금지 | 필터를 큰 카드 여러 개로 분리 |
