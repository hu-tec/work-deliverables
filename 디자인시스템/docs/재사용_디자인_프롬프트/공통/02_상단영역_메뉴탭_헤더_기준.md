# 상단영역 메뉴탭 헤더 기준

## 1. 대분류: 상단 영역의 역할

### 1.1 중분류: 상단은 설명 영역이 아니라 작업 기준점

상단 영역은 현재 위치, 현재 업무, 선택 상태, 주요 액션을 알려주는 영역이다.

소분류:
- 화면명은 업무명을 직접 쓴다.
- 보조 문구는 짧게 둔다.
- 상태와 개수는 상단에서 바로 확인되게 한다.
- 주요 액션은 오른쪽에 모은다.

### 1.2 중분류: 상단에서 줄여야 할 것

소분류:
- 긴 소개 문장
- 반복되는 안내문
- 카드형 설명 박스
- 화면 아래에서도 다시 나오는 상태 설명

## 2. 대분류: 헤더 구조

### 2.1 중분류: 기본 헤더

권장 구조:

```text
상단 헤더
  왼쪽: 현재 위치 / 전체 개수 / 화면 제목 / 짧은 요약
  오른쪽: 상태 chip / 보조 버튼 / 주요 버튼 / 닫기
```

소분류:
- H1은 `전체 회원 관리`, `결제 관리`, `신청 접수 관리`처럼 업무명을 쓴다.
- 선택 대상이 있으면 `박서연 회원 상세`, `005-Aa2`처럼 이름과 식별값을 함께 보여준다.
- 보조 설명은 한 줄로 제한한다.

### 2.2 중분류: 상세 패널 헤더

소분류:
- `넓게보기`, `닫기`는 오른쪽 상단에 둔다.
- `상담중`, `완료`, `정상` 같은 현재 상태는 넓게보기 근처에 둔다.
- 상세 내부에 같은 의미의 진한 제목바를 중복해서 만들지 않는다.
- 내부 작업 패널의 액션바는 따로 둘 수 있다.

## 3. 대분류: 탭과 메뉴

### 3.1 중분류: 탭의 목적

탭은 단순 장식이 아니라 같은 화면 안에서 데이터 범주나 업무 상태를 전환하는 장치다.

소분류:
- 1차 탭: 큰 업무 범주
- 2차 탭: 현재 업무 안의 상태나 세부 목록
- 탭 label에는 가능하면 개수를 포함한다.

예시:

```text
전체 회원 50 | 정식회원 18 | 기업회원 7 | 전문가 6
AI번역 13 | 시험응시 8 | 상담대기 4
```

### 3.2 중분류: 선택 상태

소분류:
- 선택된 탭은 진한 배경 또는 선명한 상태로 보인다.
- 비선택 탭은 연한 배경을 사용한다.
- 선택 상태를 색상만으로 표현하지 않고 text weight, border, aria 상태를 함께 쓴다.

## 4. 대분류: 버튼 위치

### 4.1 중분류: 주요 버튼

소분류:
- 저장, 신청, 접수, 검색 같은 실행 버튼은 오른쪽 또는 검색어 근처에 둔다.
- 닫기와 저장은 멀리 떨어뜨리지 않는다.
- 위험 액션은 일반 액션과 시각적으로 구분한다.

### 4.2 중분류: 상세보기 버튼

소분류:
- 행 전체 클릭으로 상세가 열리면 별도 상세 버튼 컬럼을 만들 필요가 없다.
- `넓게보기`는 상세 패널 헤더 오른쪽에 둔다.
- 넓게보기 상태에서는 테이블보다 상세 작업 영역을 우선한다.

## 공통 샘플: 밀도·헤더·카드형·표형 기준

![공통 밀도 헤더 카드 표형 번호 샘플](assets/공통_밀도헤더카드표_번호샘플.svg)

샘플 번호 기준:
- 1번: 상단 헤더는 업무명, count, 상태 chip, 주요 버튼을 한 줄에 압축한다.
- 2번: 1단 안에 2~4단을 넣어 짧은 조건과 값을 가로로 묶는다.
- 3번: 카드형은 적은 수의 독립 항목이나 요약 패널에만 쓴다.
- 4번: 표형은 많은 행을 비교, 선택, 상세 진입해야 할 때 쓴다.
- 5번: 상태는 chip과 짧은 label로 표시하고, 이모지는 보조 신호로만 제한한다.
- 6번: 최종 검수는 헤더, 밀도, 카드/표 선택, 상태 표현, 빈 공간을 함께 확인한다.

## 5. 요약표

| 영역 | 기준 |
|---|---|
| 화면 헤더 | 업무명, 개수, 짧은 요약, 주요 액션 |
| 상세 헤더 | 대상명, 식별값, 상태, 넓게보기, 닫기 |
| 탭 | 업무 범주 전환, 가능하면 count 포함 |
| 상태 위치 | 오른쪽 상단 또는 대상명 근처 |
| 금지 | 중복 제목바, 긴 설명, 상단 카드 남발 |
