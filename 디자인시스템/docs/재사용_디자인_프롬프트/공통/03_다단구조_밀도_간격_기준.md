# 다단구조 밀도 간격 기준

## 1. 대분류: 다단 구조를 쓰는 이유

### 1.1 중분류: 화면을 짧게 만들기

2단, 3단, 4단 구조는 단순히 예쁘게 나누는 장치가 아니다. 같은 맥락의 정보를 가로로 묶어 세로 스크롤을 줄이고 한 화면에서 비교하게 만드는 기준이다.

소분류:
- 짧은 값이 많은 경우 다단이 적합하다.
- 긴 설명은 무리하게 다단으로 쪼개지 않는다.
- 카드 여러 개를 크게 만드는 것보다 작은 패널을 촘촘히 놓는다.

### 1.2 중분류: 같은 맥락은 같은 줄

소분류:
- `회원유형 : 전체 일반회원 정식회원 기업회원 전문가`
- `성별 : 전체 M F`
- `상태 : 전체 완료 대기 취소`
- `기간 : 시작일 종료일 오늘 1주 1개월`

## 2. 대분류: 단수 선택 기준

### 2.1 중분류: 1단

1단은 긴 설명, 본문, 큰 표, 복잡한 입력 흐름에 사용한다.

소분류:
- 긴 안내문
- 상세 메모
- 큰 테이블
- 세로 순서가 중요한 절차

### 2.2 중분류: 1단 안의 여러 단

겉으로는 1단이지만 내부에서 2-4단으로 나누면 공간을 크게 줄일 수 있다.

소분류:
- 한 카드 안에 label/value 2열
- 한 필터 그룹 안에 옵션 2-3열
- 한 상세 패널 안에 A/B/C 섹션을 압축 배치
- 한 테이블 셀 안에 주정보/보조정보 2줄 또는 2-3개 값

### 2.3 중분류: 2단

소분류:
- 좌측 기본정보 + 우측 작업정보
- 관리자 폰트 기준 + 사용자 폰트 기준
- 카드형 예시 + 표형 예시
- 설정값 + 미리보기

### 2.4 중분류: 3단

소분류:
- 디자인 원칙 + 토큰 + 타이포그래피
- 상태 + 입력 + 결과
- 신청정보 + 처리정보 + 운영메모

### 2.5 중분류: 4단

소분류:
- 디자인 토큰 색상 묶음
- UI별 보기처럼 항목이 많은 목록
- 대시보드의 작은 운영 패널
- 검색조건 그룹

## 3. 대분류: 간격 압축 기준

### 3.1 중분류: 먼저 줄일 것

소분류:
- 반복 제목
- 카드 안쪽 padding
- row gap
- line-height
- 불필요한 가로줄
- 빈 설명 영역
- 큰 버튼 높이

### 3.2 중분류: 마지막에 줄일 것

소분류:
- 본문 가독성을 해치는 글자 크기
- 클릭 target이 필요한 사용자 화면 버튼
- 접근성 예시의 target size

### 3.3 중분류: 가로줄 없는 구분

가로줄을 모두 넣으면 촘촘한 화면이 더 복잡해 보인다.

소분류:
- 섹션 제목과 배경 톤으로 구분한다.
- label weight로 구분한다.
- 1px border는 표와 입력 구획에만 제한적으로 쓴다.
- 카드 안에 또 카드처럼 보이는 중첩 border를 피한다.

## 4. 대분류: 반응형

### 4.1 중분류: 넓은 화면

소분류:
- 4단 또는 5단까지 사용 가능하다.
- 테이블과 상세를 함께 보이게 한다.
- 상세가 열리면 테이블은 좁아져도 핵심 열이 유지되어야 한다.

### 4.2 중분류: 좁은 화면

소분류:
- BO 테이블은 완전 카드화보다 가로 스크롤을 우선한다.
- 사용자 화면은 2단을 1단으로 내릴 수 있다.
- 상세 입력은 의미 단위별로 접을 수 있다.

## 공통 샘플: 밀도·헤더·카드형·표형 기준

![공통 밀도 헤더 카드 표형 번호 샘플](assets/공통_밀도헤더카드표_번호샘플.svg)

샘플 번호 기준:
- 1번: 상단 헤더는 업무명, count, 상태 chip, 주요 버튼을 한 줄에 압축한다.
- 2번: 1단 안에 2~4단을 넣어 짧은 조건과 값을 가로로 묶는다.
- 3번: 카드형은 적은 수의 독립 항목이나 요약 패널에만 쓴다.
- 4번: 표형은 많은 행을 비교, 선택, 상세 진입해야 할 때 쓴다.
- 5번: 상태는 chip과 짧은 label로 표시하고, 이모지는 보조 신호로만 제한한다.
- 6번: 최종 검수는 헤더, 밀도, 카드/표 선택, 상태 표현, 빈 공간을 함께 확인한다.

## 5. 요약표

| 구조 | 쓰는 경우 |
|---|---|
| 1단 | 긴 설명, 본문, 큰 표 |
| 1단 안 여러 단 | 한 영역 안에 짧은 값이 많을 때 |
| 2단 | 기본정보 + 작업정보, 비교 구조 |
| 3단 | 원칙/토큰/타이포그래피 같은 대분류 |
| 4단 | UI별 보기, 검색조건, 운영 패널 |
| 줄일 우선순위 | 반복 제목, padding, row gap, 빈 설명 |
