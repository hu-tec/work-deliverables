검색필터 기준

생성일: 2026-07-02 최종 정리일: 2026-07-03 기준 파일: index.html, layout.css, table_design/table-design.css, table_design/table-design.js

이 문서는 사용자 화면 필터와 BO 고밀도 검색조건을 구분하고, 문서 작성 시 대분류·중분류·소분류를 어떻게 적용하는지 보여주는 공통 예시다. 검색조건, 테이블, 상세가 함께 있는 화면에서는 공통/11_검색기능_테이블_상세보기_통합기준.md를 먼저 적용한다.

1. 대분류: 사용자 화면 필터

1.1 중분류: 노출 범위

사용자 화면은 과도하게 많은 조건을 한 번에 노출하지 않는다.

소분류:

  • 키워드 검색
  • 1-3개 주요 카테고리 chip
  • 기간 또는 상태 필터가 필요하면 한 줄 추가
  • 활성 필터는 filter-tag로 표시

1.2 중분류: 선택 상태

소분류:

  • 버튼형 필터는 aria-pressed로 실제 선택 상태를 전달한다.
  • 전체와 개별 조건이 동시에 모호하게 선택되지 않게 한다.
  • 색만 바꾸지 말고 텍스트와 테두리도 함께 바꾼다.
<div class='filter-bar' aria-label='접수 상태'>
  <button class='filter-chip' type='button' aria-pressed='true'>전체</button>
  <button class='filter-chip' type='button' aria-pressed='false'>접수중</button>
  <button class='filter-chip' type='button' aria-pressed='false'>마감임박</button>
</div>

2. 대분류: BO 고밀도 검색조건

2.1 중분류: 조건 그룹 한 줄

BO 테이블은 dense-filter-card를 기준으로 한다.

소분류:

  • 회원유형 : 전체 일반회원 정식회원 기업회원 전문가처럼 조건명과 옵션을 한 줄에 둔다.
  • 성별 : 전체 M F처럼 짧은 그룹은 같은 열 안에서 연속 배치한다.
  • 서비스유형은 구독상태와 같은 열에 묶는다.
  • 가입채널은 알림·기기 아래 남는 공간으로 이동해 별도 행을 만들지 않는다.
  • 검색조건은 화면 폭에 맞춰 4-5단으로 구성하되 각 단 안에 다시 2-3개 조건 그룹을 둘 수 있다.

2.2 중분류: 활성 필터와 검색어

선택된 필터 태그는 별도 행을 만들지 않고 검색어와 같은 줄에 둔다.

소분류:

  • 태그는 검색조건 요약 다음, 검색어 select/input 앞에 배치한다.
  • 태그를 해제하면 남은 태그와 검색어가 즉시 앞으로 당겨진다.
  • 태그가 많으면 검색어를 밀어내지 않도록 태그 영역에 최대 폭을 둔다.
  • 필터 전체 해제, 검색, 초기화는 같은 검색 행 안에서 이어진다.
<form class='dense-filter-card' data-dense-filter>
  <div class='dense-filter-flow'>
    <fieldset class='dense-filter-group' data-single-choice>
      <legend>매칭상태 :</legend>
      <div class='dense-filter-options'>
        <button class='filter-chip' type='button' aria-pressed='true'>전체</button>
        <button class='filter-chip' type='button' aria-pressed='false'>완료</button>
        <button class='filter-chip' type='button' aria-pressed='false'>대기</button>
      </div>
    </fieldset>
  </div>

  <div class='dense-search-main'>
    <div class='dense-active-filters' data-active-filters aria-label='선택된 검색조건'></div>
    <button class='btn' type='button' data-clear-filters>필터 전체 해제</button>
    <select aria-label='검색 범위'>
      <option>전체</option>
    </select>
    <label class='dense-search-field'>
      <span class='sr-only'>검색어</span>
      <input type='search' name='keyword' placeholder='이름, 이메일, 관리번호 검색'>
    </label>
    <button class='btn primary' type='submit'>검색</button>
    <button class='btn' type='reset'>초기화</button>
  </div>
</form>

2.3 중분류: 정렬과 밀도

소분류:

  • 조건명 legend는 옵션과 한 줄에서 읽히는 짧은 폭으로 둔다.
  • 옵션 영역은 flex로 배치하고 같은 그룹 안에서만 줄바꿈한다.
  • 조건 블록 사이에는 얇은 세로 구분선을 둘 수 있다.
  • 기간 조건은 가입일순 / 시작일 / 종료일 / 빠른 기간 버튼을 한 줄에 둔다.
  • 화면 아래에 중복된 선택 필터 행을 만들지 않는다.

3. 대분류: 권장 조건 세트

3.1 중분류: 회원

소분류:

  • 회원유형: 전체, 일반회원, 정식회원, 기업회원, 전문가
  • 성별: 전체, M, F
  • 구독상태: 전체, 프리미엄, 스탠다드, 베이직, free
  • 서비스유형: 시험역, 통번역, 교육센터, 전시/행사, 시험사이트
  • 매칭상태: 전체, 완료, 대기, 취소, 검토중
  • 결제상태: 전체, 정상, 미납, 환불, 정산대기
  • 가입채널: 전체, 이메일, 홈페이지, 구글, 추천, 관리자등록, 기관계약

3.2 중분류: 결제와 매칭

소분류:

  • 결제 유형: 구독, 서비스의뢰, 시험응시, 문서구매
  • 결제 상태: 결제완료, 정산대기, 환불완료, 결제취소
  • 결제 수단: 카드, 계좌이체, 체크카드, 토스페이, 가상계좌
  • 매칭 조건: 유형, 카테고리, 언어, 분야, 배정상태, 진행상태, 결제상태

4. 대분류: 금지

4.1 중분류: 구조 금지

소분류:

  • BO 필터를 큰 카드 여러 개로 나누지 않는다.
  • 회원유형, 성별, 구독상태처럼 짧은 옵션을 각각 여러 줄로 쌓지 않는다.
  • 선택 필터를 검색어와 분리된 독립 행으로 만들지 않는다.
  • 가입채널만을 위해 검색조건 높이를 한 줄 더 늘리지 않는다.

4.2 중분류: 상태 금지

소분류:

  • 전체와 개별 조건의 선택 상태를 모호하게 두지 않는다.
  • 활성 필터와 원래 조건의 상태를 다르게 유지하지 않는다.
  • 시각적 active만 바꾸고 aria-pressed를 갱신하지 않는다.
