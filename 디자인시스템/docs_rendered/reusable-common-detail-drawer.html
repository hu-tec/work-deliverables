상세보기 Drawer 패널 기준

1. 대분류: 상세보기의 역할

1.1 중분류: 상세보기는 단순 보기 영역이 아니다

관리자 화면의 상세보기는 선택된 행을 처리하는 작업 공간이다.

소분류:

  • 선택 대상 식별
  • 상태 판단
  • 입력과 수정
  • 이력 확인
  • 저장과 전환
  • 메모 기록

1.2 중분류: inline Drawer 우선

소분류:

  • 테이블 행 클릭 시 오른쪽 inline Drawer를 연다.
  • overlay modal보다 테이블과 같은 작업 맥락 안에 붙인다.
  • 닫기, ESC 닫기, focus 복귀를 지원한다.
  • 넓게보기 상태에서는 상세가 전체 작업폭을 쓸 수 있다.

2. 대분류: 상세 헤더

2.1 중분류: 헤더 구성

상세 헤더
  왼쪽: 테이블/업무명, 대상명, 식별번호, 짧은 요약
  오른쪽: 상태 chip, 넓게보기, 닫기

소분류:

  • 선택 대상이 누구인지 바로 보이게 한다.
  • 상담중, 완료, 정상 같은 상태는 오른쪽 상단에 둔다.
  • 같은 의미의 진한 제목바를 내부에 중복하지 않는다.

2.2 중분류: 내부 액션바

소분류:

  • 저장, 상담이력, 전환, FAIL 같은 업무 액션은 내부 액션바에 둘 수 있다.
  • 액션바는 헤더와 역할이 다르므로 중복 제목을 넣지 않는다.

3. 대분류: A/B/C 패널 구조

3.1 중분류: A 영역

A는 선택 대상의 기본정보 마스터다.

소분류:

  • 이름, 영문명, 아이디, 관리번호
  • 이메일, 휴대폰, 집전화
  • 거주지, 국가
  • 회원유형, 가입일, 채널
  • 학력, 해외 체류, 어학점수, 이력사항
  • 사용 목적과 주요 체크값

기준:

  • A는 B와 함께 보일 수 있도록 충분히 넓히되 세로 간격은 줄인다.
  • label/value를 2열로 압축할 수 있다.
  • B가 열렸을 때도 A의 핵심 정보가 스크롤 없이 최대한 보이게 한다.

3.2 중분류: B 영역

B는 상담/운영 작업 정보다.

소분류:

  • 첫상담
  • 최종상담
  • 부재횟수
  • 최근부재
  • 교육장
  • 수정정보
  • 다음통화 예정일시
  • LT예정일시
  • 상담일
  • 상담자
  • 결과
  • 상담내용 정리
  • 상담이력 피드 로그

기준:

  • B의 핵심 운영정보는 compact grid로 둔다.
  • 상담내용 정리와 상담이력은 B 아래에 붙인다.
  • 입력과 이력은 구분한다.

3.3 중분류: C 영역

C는 납부 상세정보와 회계 정산 영역이다.

소분류:

  • 센터 입력 영역
  • 회계 영역
  • 전형료, 입학금, 수업료, 교재비
  • 납입일자, 수납센터, 상태, 방식, 금액, 할인사유, 개월, 카드사, 승인번호
  • 회사입금일, 회계상태, 수수료, 실입금액, 비고, 회계특이사항

기준:

  • 날짜 입력은 달력 선택이 가능해야 한다.
  • 센터 입력과 회계 영역은 색 또는 헤더로 구분한다.
  • C는 표형이 적합하다.

4. 대분류: 접기/펼치기

4.1 중분류: 기본 닫힘

많은 옵션이 항상 펼쳐져 세로 공간을 차지하면 안 된다.

소분류:

  • 상담결과 옵션은 기본 닫힘으로 둔다.
  • 클릭하면 미상담, 완료, LT예약, 다음등록, 실종, 부재, 기타가 보인다.
  • 선택 후 다시 닫혀 한 줄 높이로 돌아온다.

4.2 중분류: 계속 보여야 하는 정보

소분류:

  • 현재 선택값
  • 대상명과 식별번호
  • 저장/닫기/넓게보기
  • 업무 상태

5. 요약표

영역역할
상세 헤더대상 식별, 상태, 넓게보기, 닫기
내부 액션바저장, 상담이력, 전환, FAIL
A기본정보 마스터
B상담 운영정보, 메모, 이력
C납부, 증명서, 회계 정산
접기많은 옵션은 기본 닫힘
