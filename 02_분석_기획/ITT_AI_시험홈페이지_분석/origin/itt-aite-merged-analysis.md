# itt.or.kr + aite-test.imweb.me 통합 분석

- 분석 대상: https://www.itt.or.kr, https://aite-test.imweb.me
- 확인일: 2026-05-21
- 목적: 기존 ITT 시험위원회 사이트와 신규 AITe AI 자격시험 사이트를 하나의 서비스/브랜드 구조로 합치는 방향 정리

## 1. 통합 관점 요약

두 사이트는 역할이 다릅니다.

- `itt.or.kr`: 시험 운영, 접수, 일정, 결과, 자격증 출력 중심의 공식 운영 사이트
- `aite-test.imweb.me`: AI 자격시험 브랜드 설명, 가치 제안, 신규 시험 소개 중심의 마케팅 사이트

따라서 단순 병합보다 `공식 통합 포털 + 시험별 상세 랜딩 + 운영 기능` 구조가 적합합니다. ITT의 신뢰성과 운영 기능을 유지하면서, AITe의 AI 시험 메시지와 확장성을 흡수하는 방식이 좋습니다.

## 2. 권장 통합 방향

### 권장 구조

통합 사이트는 `AITe / ITT 통합 자격시험 포털`로 설계하고, ITT는 전통 통번역 자격의 핵심 브랜드로 유지합니다.

- 상위 브랜드: AITe 또는 ITT-AITe 통합 시험센터
- 기존 자산: ITT 시험위원회 공식성, 일정/접수/결과/자격증 기능
- 신규 자산: AI 번역, AI 프롬프트, AI 윤리 시험
- 공통 원칙: 모든 시험은 등급, 일정, 응시료, 접수, 결과 확인을 같은 UX로 제공

### 도메인 전략

`aite-test.imweb.me`는 임시 빌더 도메인 성격이 강하므로 공식 서비스에는 적합하지 않습니다.

권장안:

1. `itt.or.kr` 내에 AITe 섹션을 신설
2. 별도 공식 도메인 사용 시 `aite.or.kr` 또는 유사 도메인 연결
3. 단기적으로는 `itt.or.kr/aite` 또는 `aite.itt.or.kr` 형태가 운영 신뢰도 측면에서 가장 안정적

## 5. 콘텐츠 통합 원칙

- ITT의 시험 운영 정보는 보존합니다.
- AITe의 AI 시험 가치 제안은 시험 소개와 상세 페이지 상단에 배치합니다.
- 이미지로 제공되는 표 정보는 HTML 텍스트 표로 전환합니다.
- “AI 윤리 시험”은 공통 필수 과목으로 별도 페이지와 각 시험 상세 페이지 양쪽에 노출합니다.
- 시험 일정은 하나의 통합 일정 데이터로 관리합니다.
- 접수/결제/응시확인서/결과/자격증 출력은 하나의 계정 흐름으로 통합합니다.

## 6. 통합 시 우선 수정해야 할 문제

1. AITe 사이트의 오탈자와 중복 문구 정리
2. 시험 분야 수, 합격 기준, 응시료, 일정의 표현 통일
3. AI 윤리 시험 링크와 상세 페이지 연결 검수
4. ITT 사이트의 실제 사이트맵 페이지 복구
5. 시험 정보 이미지의 텍스트화
6. 레거시 인코딩/EUC-KR 페이지의 UTF-8 전환
7. 모바일 전용 리다이렉트 대신 반응형 웹 구조 적용
8. 개인정보처리방침, 이용약관, 환불규정의 최신 표기 통합

## 8. 통합 후 기대 효과

- ITT의 기존 응시자와 AITe의 신규 AI 자격 수요를 한 곳으로 모을 수 있습니다.
- 시험 접수와 결과 확인 같은 운영 기능을 중복 구축하지 않아도 됩니다.
- AI 번역/프롬프트/윤리 시험이 ITT의 공신력과 연결되어 신뢰도가 높아집니다.
- 검색엔진에는 “통번역 자격증”, “AI 번역 자격증”, “프롬프트 자격증”, “AI 윤리 시험” 키워드를 한 도메인에서 축적할 수 있습니다.
- 관리자 입장에서는 일정, 공지, 응시료, 환불규정, 결과 발표를 일관되게 관리할 수 있습니다.
