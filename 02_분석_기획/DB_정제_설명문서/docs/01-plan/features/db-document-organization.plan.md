# db-document-organization - Plan Document

> Version: 1.0.0 | Date: 2026-05-26 | Status: Approved
> Level: Starter

## 1. Overview

### 1.1 Purpose

`수집된DB`와 `휴텍씨DB`에 흩어진 CSV 자료를 일반 사용자가 제목만 보고도
용도를 파악할 수 있는 주제별 문서 묶음으로 재구성한다.

### 1.2 Background

현재 CSV는 여러 표가 한 파일에 나란히 배치되어 있고, 긴 문제와 답안 자료도
하나의 파일에 포함되어 있다. 원본은 기획 자료로 보존하면서 열람용 정리본이
별도로 필요하다.

## 2. Goals

- [x] 서비스 분류, 시험 운영, 교육 자료, 문제은행, 서비스 기획으로 구분한다.
- [x] 긴 문제은행은 대분류별 파일로 분리하고 문제와 답안을 함께 보존한다.
- [x] 생성된 모든 문서에서 원본 출처를 확인할 수 있게 한다.

### 2.1 Non-Goals

- 원본 CSV의 값 수정, 오탈자 교정 또는 확정되지 않은 기획 항목의 확정
- 실제 서비스용 데이터베이스 스키마 설계

## 3. Scope

### 3.1 In Scope

- 입력 파일 9개 전체의 내용 파악 및 주제별 정리본 생성
- 읽는 법과 파일 목록을 설명하는 안내 문서
- 동일 규칙으로 정리본을 다시 만들 수 있는 생성 스크립트

### 3.2 Out of Scope

- 원본 파일 삭제 또는 이동
- 개인정보/업무정보의 정합성 검증

## 4. Success Criteria

- [ ] 새 폴더 안에서 문서가 주제별 하위 폴더로 분리된다.
- [ ] 문제은행 본문 47건이 분류별 파일에 누락 없이 포함된다.
- [ ] 주요 표 형식 문서는 출처 열을 포함하며 UTF-8 CSV로 열린다.
- [ ] 안내 문서에 원본의 미확정/중복/오탈자 가능성을 명시한다.

## 5. Risks & Mitigations

| Risk | Impact | Mitigation |
|------|--------|------------|
| 원본 시트가 병렬 표 구조라 열 관계 해석이 불명확함 | 항목이 잘못 연결될 수 있음 | 관계를 추정하지 않고 독립 목록 또는 출처 열로 제공 |
| 긴 문제/답안 내용의 누락 | 문제은행 사용 불가 | 행 수와 분리 후 합계 검증 |
| 초안 값이 확정 정보로 오해됨 | 잘못된 의사결정 | 안내 문서에 초안 및 확인 필요 표기 |

## 6. Output

- `일반사용자용_정리DB/`: 최종 열람용 문서
- `일반사용자용_정리DB/_생성도구/정리본_생성.py`: 재생성 도구
