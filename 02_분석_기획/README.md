# 02 · 분석·기획

분석 결과, 서비스 기획, DB 설명과 원본 자료를 보관합니다.

| 폴더 | 내용 |
|---|---|
| `ITT_홈페이지 분석안/` | ITT 홈페이지 분석과 HTML 샘플 |
| `ITT_AI_시험홈페이지_분석/` | ITT·AI 시험 홈페이지 분석 결과 |
| `타임즈_테솔_분석자료/` | 타임즈·테솔 사이트 분석 |
| `테솔_ITT_FAQ분석/` | TESOL·ITT FAQ 분석 |
| `내부 관리망분석/` | 인트라넷 화면 목록과 개선안 |
| `보유 스킬 및 상세 체크리스트_고도화/` | 스킬 체크리스트 원본과 개선안 |
| `서비스_기획/` | 서비스 목적·범위·요구사항 |
| `DB_원본_엑셀/` | DB 원본 엑셀 |
| `DB_정제_설명문서/` | DB 정제 과정과 사용자용 읽기 자료 |
| `sites.md` | 참고 사이트 목록 |

DB 원본과 정제 설명은 역할이 다릅니다. 원본 값을 바꿔야 하는 작업이면 원본과 변환 결과를 각각 대조합니다.
