# 파일 추출 + 업무 프롬프트 생성기 고밀도 수정안 V2

## 0. 이번 수정 반영 사항

| 사용자 의견 | 수정 반영 |
|---|---|
| 관련 파일찾기에 대/중/소가 왜 있는지 의미가 불명확함 | 파일 검색 영역에서는 제거하고, **파일 결과 저장용 분류/태그** 영역으로 이동 |
| 대/중/소가 필요하다면 언제 쓰는지 구분 필요 | 검색 조건이 아니라 **선택 파일을 저장·정리할 때 붙이는 분류 태그**로 재정의 |
| 생성기별 버튼이 너무 촘촘해서 글자가 안 보임 | 버튼 나열 대신 **생성기 선택 드롭다운 + 크게보기 모달 + 가로폭 조절** 구조로 변경 |
| 칸을 늘렸다 줄였다 하고 싶음 | 좌/중/우 패널 사이에 **드래그 핸들** 추가 |
| 파일결과, 설정저장, 도움말이 안 눌림 | 모든 상단 탭을 실제 전환되도록 수정 |
| 화면을 꽉 채우되 사용성이 필요함 | 한 화면 고밀도 구조는 유지하되, 상세 내용은 접기/펼치기·모달로 처리 |

## 1. 대/중/소 분류 위치 변경

### 기존 문제

관련 파일 찾기 영역에 대/중/소 분류가 들어가 있으니, 사용자가 봤을 때  
“파일을 찾는 조건인지, 파일을 분류하는 기준인지”가 헷갈릴 수 있습니다.

### 수정 방향

대/중/소는 파일 검색 조건이 아니라 **찾은 파일을 저장하거나 정리할 때 붙이는 분류 태그**로 이동합니다.

| 구분 | 기존 | 수정 |
|---|---|---|
| 위치 | STEP 1 관련 파일 찾기 안에 배치 | 파일결과 탭 또는 결과 저장 설정 영역으로 이동 |
| 의미 | 검색 조건처럼 보임 | 저장 분류 / 태그 / 프로젝트 정리 기준 |
| 사용 시점 | 검색 전 | 검색 후 선택 파일 정리 시 |
| 기능 | 대/중/소 체크 | 대/중/소 태그 선택, 수정, 추가, 즐겨찾기 저장 |

## 2. 관련 파일 찾기 화면 수정

### 핵심만 남긴 파일 찾기 조건

| 영역 | 항목 |
|---|---|
| 폴더 | 원본 폴더, 결과 저장 폴더 |
| 파일조건 | 문서 전체 / PDF만 / 표 포함 / 전체 |
| 기간 | 최근 1년 / 최근 6개월 / 전체 |
| 버전 | 최신·최종 우선 / 초안 포함 / 반려 포함 |
| 키워드 | 반드시 포함, 관련성 강화, 보류/검토, 제외 |
| 실행 | 관련 파일 찾기, 선택 파일 복사, 미리보기 |

### 검색 결과 후 분류 태그

| 영역 | 항목 |
|---|---|
| 대분류 | 정부사업, 자격증, 교육과정, 법무, 업무관리 |
| 중분류 | 사업계획서, 운영규정, 커리큘럼, 증빙자료, 지시사항 |
| 소분류 | 시장조사, 예산, 반려, 차시표, 계약, 회의록 등 |
| 기능 | 체크, 수정, 추가, 즐겨찾기 저장 |

## 3. 생성기 선택 방식 수정

### 기존 문제

생성기별 버튼을 좁은 칸에 모두 넣으니 글자가 한 글자씩만 보입니다.

### 수정 방식

| 기능 | 수정 |
|---|---|
| 생성기 전환 | 드롭다운 선택 방식으로 변경 |
| 상세 보기 | `⛶ 크게보기` 버튼으로 모달창 표시 |
| 칸 조절 | 좌측/중앙/우측 패널 사이 드래그 가능 |
| 빠른 전환 | Ctrl+1~5 단축키 유지 |
| 좁은 화면 대응 | 버튼 대신 짧은 라벨 + 툴팁 사용 |

## 4. 탭 기능 수정

상단 탭은 실제로 전환되어야 합니다.

| 탭 | 내용 |
|---|---|
| ① 통합작업 | 파일찾기 + 업무프롬프트 + 빠른선택 한 화면 |
| ② 파일결과 | 검색된 파일 목록, 선택 파일, 저장 분류 태그 |
| ③ 설정저장 | 회사 규정, 즐겨찾기, 고정 멘트, 기본값 저장 |
| ④ 도움말 | 단축키, 사용 순서, 생성기별 설명 |

```text
┌──────────────────────────────────────────────────────────────────────────────┐

├──────────────────────────────────────────────────────────────────────────────┤
│ [① 통합작업] [② 파일결과] [③ 설정저장] [④ 도움말]                            │
├─────────────┬─drag─┬──────────────────────────────┬─drag─┬──────────────────┤
│ 파일 찾기   │      │ 업무 프롬프트 설정             │      │ 빠른 선택/규정   │
│ - 폴더       │      │ - 생성기 드롭다운              │      │ - 대상/말투      │

├─────────────┴──────┴──────────────────────────────┴──────┴──────────────────┤
│ 파일 결과 요약 + 생성 프롬프트 미리보기                                        │
└──────────────────────────────────────────────────────────────────────────────┘
```

## 6. 생성기별 전용 설정 유지

생성기별 전용 체크박스는 유지하되, 화면에는 기본 3단 요약만 보이고,  
`⛶ 크게보기`를 누르면 전체 체크박스를 큰 창에서 볼 수 있게 합니다.

| 생성기 | 전용 영역 |
|---|---|
| 사업계획서 | 기본/문제, 시장/수익, 경쟁/도표, 사업화, 가치/리스크, 출력 |
| 자격증 규정 | 기본, 규정, 등급, 반려대응, 출력 |
| 교육과정 | 기본, 과정, 운영, 안내, 출력 |
| 법무증빙 | 기본, 사건, 증거, 질문, 출력 |
| 업무정리 | 기본, 정리, 우선순위, 전달, 리스크, 출력 |

## 7. 개발 반영 우선순위

| 우선순위 | 기능 | 이유 |
|---|---|---|
| 1 | 대/중/소 분류를 파일 결과/저장 태그로 이동 | 파일 찾기와 분류 저장의 의미를 분리 |
| 2 | 상단 탭 실제 작동 | 파일결과, 설정저장, 도움말 접근 가능 |
| 3 | 패널 드래그 조절 | 생성기명이 잘리지 않도록 화면 폭 조절 |
| 4 | 생성기 선택 드롭다운 + 크게보기 | 촘촘하지만 읽을 수 있는 구조 |
| 5 | 고밀도 체크박스 유지 | 한 화면 정보량 유지 |
| 6 | 모달/드롭다운 상세 설정 | 화면을 넓게 쓰지 않고 필요할 때만 확장 |
