④ 도움말 - 사용 순서

  1. 관련 파일 찾기에서 폴더와 키워드만 간단히 입력
  2. 파일결과 탭에서 필요한 파일 선택
  3. 필요하면 저장용 대/중/소 태그 지정
  4. 업무 프롬프트에서 생성기와 단계 선택
  5. 내 멘션을 두서없이 입력 후 프롬프트 생성
