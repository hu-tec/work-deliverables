# 휴텍씨 시험 통합 플랫폼 기능 상세 정의

> description: 이 문서는 화면에 보이는 요소를 나열하는 문서가 아니라, 개발자가 기능을 구현할 수 있도록 기능별 입력값, 동작, 예외, 이동, 데이터, 확인 필요 사항을 고정 포맷으로 정리하는 문서다.

## 기능 상세 정의 작성 기준

기능은 메뉴명이나 화면명만으로 정의하지 않고, 사용자가 실제로 수행하는 업무 단위로 나눈다.  
각 기능은 아래 고정 포맷을 기준으로 작성한다.

### 고정 포맷

```md
## 기능명

### 목적
- 이 기능이 사용자에게 제공하는 핵심 목적을 1~2줄로 작성한다.

### 사용자/권한
- 이 기능을 사용할 수 있는 사용자 역할을 작성한다.
- 예: 비회원, 회원, 수험생, 출제자, 채점자, 관리자

### 화면 요소
- 입력창, 버튼, 체크박스, 탭, 안내 문구, 링크, 모달 등 화면에 필요한 요소를 작성한다.

### 입력값/검증 규칙
- 사용자가 입력하는 값과 필수 여부, 형식, 길이, 중복 여부, 일치 여부를 작성한다.

### 동작
- 사용자가 버튼을 누르거나 값을 입력했을 때 시스템이 처리해야 하는 동작을 순서대로 작성한다.

### 성공 시 처리
- 정상 처리 후 노출 문구, 이동 화면, 상태 변경, 저장 데이터 등을 작성한다.

### 실패/예외 처리
- 미입력, 형식 오류, 인증 실패, 권한 없음, 중복, 만료 등 실패 케이스별 처리 방식을 작성한다.

### 이동/연결 화면
- 이 기능에서 이동할 수 있는 다음 화면이나 연결 기능을 작성한다.

### 데이터/API
- 저장하거나 조회해야 하는 데이터, 필요한 API, 외부 인증 연동 등을 작성한다.

### 확인 필요
- 화면만으로 확정할 수 없어서 기획/운영/개발 확인이 필요한 사항을 작성한다.
```

이 포맷으로 작성하면 기능 누락을 줄이고, 프론트엔드 화면 구현, 백엔드 API 설계, QA 테스트 케이스 작성까지 같은 기준으로 연결할 수 있다.

## 로그인

### 목적
- 사용자가 본인 계정 또는 소셜 계정으로 서비스에 접속할 수 있게 한다.

### 사용자/권한
- 비회원
- 로그아웃 상태의 기존 회원

### 화면 요소
- 아이디 입력창
- 비밀번호 입력창
- 로그인 상태 유지 체크박스
- 로그인 버튼
- 카카오 로그인 버튼
- 네이버 로그인 버튼
- 구글 로그인 버튼
- 아이디 찾기 링크
- 비밀번호 찾기 링크
- 회원가입 링크

### 입력값/검증 규칙
- 아이디: 필수 입력
- 비밀번호: 필수 입력
- 소셜 로그인은 각 플랫폼 인증 완료 후 서비스 계정과 연결되어야 한다.

### 동작
- 아이디와 비밀번호 입력 후 로그인 버튼 클릭 시 로그인 요청을 보낸다.
- 로그인 상태 유지 체크 시 로그인 세션 또는 토큰 유지 기간을 연장한다.
- 카카오/네이버/구글 로그인 클릭 시 해당 소셜 인증 화면으로 이동한다.

### 성공 시 처리
- 로그인 성공 시 사용자 역할에 맞는 메인 화면으로 이동한다.
- 로그인 상태 유지가 체크된 경우 재접속 시 로그인 상태를 유지한다.

### 실패/예외 처리
- 아이디 미입력: 아이디 입력 안내 문구를 노출한다.
- 비밀번호 미입력: 비밀번호 입력 안내 문구를 노출한다.
- 계정 정보 불일치: 아이디 또는 비밀번호가 올바르지 않다는 안내를 노출한다.
- 소셜 로그인 실패: 인증에 실패했다는 안내를 노출하고 로그인 화면에 머무른다.
- 정지/탈퇴 계정: 로그인 불가 안내와 문의 안내를 노출한다.

### 이동/연결 화면
- 아이디 찾기
- 비밀번호 찾기
- 회원가입
- 소셜 로그인 인증 화면
- 로그인 후 역할별 메인 화면

### 데이터/API
- 로그인 API
- 소셜 로그인 인증 API
- 세션 또는 토큰 발급
- 로그인 상태 유지 설정값

### 확인 필요
- 아이디가 이메일 형식인지 일반 ID 형식인지 확인 필요
- 로그인 성공 후 역할별 이동 화면 확인 필요
- 로그인 상태 유지 기간 확인 필요
- 소셜 로그인 신규 사용자 자동 회원가입 여부 확인 필요

## 아이디 찾기

### 목적
- 사용자가 본인인증 후 가입된 아이디를 확인할 수 있게 한다.

### 사용자/권한
- 비회원
- 아이디를 잊은 기존 회원

### 화면 요소
- 본인인증 진입 버튼
- 본인인증 완료 후 아이디 노출 영역
- 로그인 버튼
- 비밀번호 찾기 버튼
- 회원가입 버튼
- 결과 안내 문구

### 입력값/검증 규칙
- 본인인증 정보는 외부 인증 수단의 필수값을 따른다.
- 아이디는 전체 노출이 아니라 마스킹된 형태로 노출한다.
- 예: `xxxx@xxxx.com`

### 동작
- 사용자가 본인인증을 진행한다.
- 본인인증 성공 후 가입 계정 존재 여부를 조회한다.
- 가입된 아이디가 있으면 마스킹된 아이디를 노출한다.
- 가입된 아이디가 없으면 불일치 안내를 노출한다.

### 성공 시 처리
- 본인인증 후 아이디가 노출된다.
- 하단에 로그인 버튼과 비밀번호 찾기 버튼이 나타난다.

### 실패/예외 처리
- 일치하는 아이디가 없는 경우 `"일치하는 정보가 없습니다"` 텍스트를 노출한다.
- 일치하는 아이디가 없는 경우 하단에 회원가입 버튼을 노출한다.
- 본인인증 실패 시 인증 실패 안내를 노출한다.

### 이동/연결 화면
- 로그인
- 비밀번호 찾기
- 회원가입
- 본인인증 화면

### 데이터/API
- 본인인증 API
- 아이디 조회 API
- 사용자 계정 조회 데이터

### 확인 필요
- 본인인증 수단 확인 필요
- 아이디 마스킹 규칙 확인 필요
- 동일 본인인증 정보로 여러 계정이 있는 경우 처리 방식 확인 필요

## 비밀번호 찾기

### 목적
- 사용자가 가입된 아이디를 입력해 비밀번호 재설정 링크를 받을 수 있게 한다.

### 사용자/권한
- 비회원
- 비밀번호를 잊은 기존 회원

### 화면 요소
- 아이디 입력창
- 비밀번호 찾기 버튼
- 아이디 찾기 버튼
- 재설정 링크 전송 버튼
- 로그인 버튼
- 계정 확인 안내 문구

### 입력값/검증 규칙
- 아이디: 필수 입력
- 아이디는 가입된 계정이어야 한다.

### 동작
- 사용자가 아이디를 입력하고 비밀번호 찾기 버튼을 클릭한다.
- 가입된 계정이 확인되면 재설정 링크 발송 안내를 노출한다.
- 안내 문구 예시: `"가입된 계정을 확인했습니다. 아래 이메일로 비밀번호를 재설정할 수 있는 링크를 보내드리겠습니다. xxxxx@xxxx.com"`
- 사용자가 재설정 링크 전송 버튼을 클릭하면 이메일로 링크를 발송한다.

### 성공 시 처리
- 재설정 링크 전송 후 발송 완료 안내를 노출한다.
- 사용자는 로그인 화면으로 이동할 수 있다.

### 실패/예외 처리
- 아이디 미입력: 아이디 입력 안내 문구를 노출한다.
- 가입되지 않은 아이디: 일치하는 계정이 없다는 안내를 노출한다.
- 이메일 발송 실패: 잠시 후 다시 시도하라는 안내를 노출한다.
- 재설정 요청 횟수 초과: 일정 시간 후 다시 시도하라는 안내를 노출한다.

### 이동/연결 화면
- 아이디 찾기
- 로그인
- 비밀번호 재설정하기

### 데이터/API
- 계정 확인 API
- 비밀번호 재설정 링크 발송 API
- 이메일 발송 이력
- 재설정 토큰

### 확인 필요
- 재설정 링크 유효 시간 확인 필요
- 재설정 링크 재발송 제한 정책 확인 필요
- 이메일 마스킹 규칙 확인 필요

## 비밀번호 재설정하기

### 목적
- 사용자가 재설정 링크를 통해 새 비밀번호를 등록할 수 있게 한다.

### 사용자/권한
- 비밀번호 재설정 링크를 받은 사용자

### 화면 요소
- 새 비밀번호 입력창
- 새 비밀번호 확인 입력창
- 비밀번호 재설정 버튼
- 비밀번호 변경 버튼
- 아이디 찾기 버튼
- 완료 안내 문구

### 입력값/검증 규칙
- 새 비밀번호: 필수 입력
- 새 비밀번호 확인: 필수 입력
- 영문, 숫자, 특수문자를 포함해야 한다.
- 8자 이상이어야 한다.
- 새 비밀번호와 새 비밀번호 확인 값이 일치해야 한다.

### 동작
- 사용자가 새 비밀번호와 확인 비밀번호를 입력한다.
- 비밀번호 재설정 또는 비밀번호 변경 버튼 클릭 시 검증을 수행한다.
- 검증 통과 시 비밀번호를 변경한다.

### 성공 시 처리
- 비밀번호 재설정 완료 시 `"비밀번호가 변경되었습니다."` 화면 또는 안내 문구로 이동한다.
- 완료 화면에서 로그인 화면으로 이동할 수 있다.

### 실패/예외 처리
- 비밀번호 미입력: 비밀번호 입력 안내 문구를 노출한다.
- 비밀번호 확인 미입력: 비밀번호 확인 입력 안내 문구를 노출한다.
- 비밀번호 형식 불일치: 영문, 숫자, 특수문자 포함 8자 이상 안내를 노출한다.
- 비밀번호 불일치: 비밀번호가 일치하지 않는다는 안내를 노출한다.
- 재설정 링크 만료: 링크가 만료되었다는 안내와 비밀번호 찾기 이동 버튼을 노출한다.

### 이동/연결 화면
- 로그인
- 아이디 찾기
- 비밀번호 찾기
- 비밀번호 변경 완료 화면

### 데이터/API
- 비밀번호 재설정 토큰 검증 API
- 비밀번호 변경 API
- 비밀번호 변경 이력

### 확인 필요
- 완료 화면이 별도 페이지인지 모달/문구 노출인지 확인 필요
- 이전 비밀번호 재사용 금지 여부 확인 필요
- 비밀번호 실패 횟수 제한 여부 확인 필요

## 회원가입

### 목적
- 신규 사용자가 서비스 계정을 생성할 수 있게 한다.

### 사용자/권한
- 비회원

### 화면 요소
- 회원가입 입력 폼
- 약관 동의 영역
- 가입 버튼
- 로그인 이동 버튼
- 소셜 회원가입(카카오 간편가입, 네이버 간편 가입, 구글 간편가입) 버튼

### 입력값/검증 규칙
- 아이디 또는 이메일: 필수 입력, 중복 확인 필요
- 비밀번호: 필수 입력, 영문/숫자/특수문자 포함 8자 이상
- 비밀번호 확인: 필수 입력, 비밀번호와 일치 필요
- 이름: 필수 입력
- 휴대폰 번호: 본인인증 또는 연락처 검증 필요
- 약관 동의: 필수 약관 동의 필요
- 약관은 이용약관 동의[필수], 개인정보 수집·이용 동의[필수]. 마케팅 메일 수신 동의(선택)

### 동작
- 사용자가 필수 정보를 입력한다.
- 아이디 또는 이메일 중복 여부를 확인한다.
- 약관 동의와 본인인증 완료 여부를 확인한다.
- 가입하기 버튼 클릭 시 회원가입 요청을 보낸다.
- 약관 우측에 전문보기를 누를 시, 모달이 나타나며 상세 내용이 표시된다.

### 성공 시 처리
- 회원가입 완료 안내를 노출한다.
- 로그인 화면 또는 가입 완료 화면으로 이동한다.

### 실패/예외 처리
- 필수값 미입력: 항목별 입력 안내 문구를 노출한다.
- 아이디/이메일 중복: 이미 가입된 계정이라는 안내를 노출한다.
- 비밀번호 형식 불일치: 비밀번호 규칙 안내를 노출한다.
- 비밀번호 불일치: 비밀번호가 일치하지 않는다는 안내를 노출한다.
- 필수 약관 미동의: 약관 동의 안내를 노출한다.
- 본인인증 실패: 인증 실패 안내를 노출한다.
