# 휴텍씨 시험 평가 사이트 폴더 안내

| 폴더 | 역할 |
|---|---|
| `hutechc_app-main(휴텍씨_기존홈페이지_클론)/` | 기존 홈페이지를 참고·복제한 앱 소스 |
| `hutechc_design_resource(휴텍씨_시험_플랫폼_이미지_리소스)/` | 시험 플랫폼 디자인 이미지 리소스 |
| `hutechc_test_for_pdf/` | PDF 관련 시험 자료 |
| `시험_홈페이지_분석/` | 시험 홈페이지 분석 자료 |
| `예전작업/` | 이전 제작 단계의 작업 이력 |

이 폴더의 `예전작업/`과 랜딩페이지 `ver1`은 서로 다른 이력입니다. 교육·시험·협회 랜딩의 버전별 화면은 [`../랜딩페이지/랜딩페이지3종/README.md`](../../01_화면_디자인/랜딩페이지/랜딩페이지3종/README.md)에서 찾으세요.
