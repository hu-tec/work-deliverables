3. 홈페이지 구성 방향

휴텍씨 홈페이지는 교육, 시험, 협회 3개 랜딩페이지 구조를 기준으로 구성합니다.

시험

타임즈 테솔 / AITE / ITT

기존 ITT 소개를 기반으로 그리너스, AITE 자료를 통합해 미래사업 메시지를 강조합니다.

교육

TESOL-v3 과정 / AI Teacher

교육 페이지 안에 강사 영역을 하위 탭으로 추가합니다.

협회

ITT 협회 소개

협회 소개, 자격관리, 연혁, 윤리 기준 성격의 콘텐츠를 묶습니다.

공통 분석

통합 분석 화면 / 랜딩페이지 자료

교육·시험·협회를 같은 구조와 용어로 연결할 때 공통 기준으로 확인합니다.

11. 다음 작업자 체크리스트

  • index.html에서 전체 산출물 위치 확인
  • 분석 자료는 analyze.html에서 별도 확인
  • 새 페이지 제작 전 자료전달 가이드 확인
  • BO 화면은 관리자 기준 문서 우선 적용
  • 사용자 랜딩페이지는 랜딩페이지3종 구조 확인
  • 시험 평가 사이트는 권한별 UI 분리 기준 확인
  • 외부 접속 URL은 sites.md에서 확인
  • 테이블형 화면은 날짜, 상태, 선택 작업을 한 행에 배치
  • 짧은 설명과 기준은 2~4단 그리드로 묶어 확인
