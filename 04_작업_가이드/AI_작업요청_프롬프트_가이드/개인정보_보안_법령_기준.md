# 개인정보·보안 법령·기준

**이 탭의 용도:** 자격증 발급·본인확인 서비스에서 수집·보관·위탁·안전조치·파기 의무와 실제 소스 증거를 연결한다. **2026-10-25 확인 기준**이며 운영 주체, 자격증 종류, 계약 관계에 따라 적용 여부를 다시 판단한다.

## 먼저 구분할 네 가지

| 구분 | 뜻 | 검토 결과에 적을 것 |
|---|---|---|
| 법률·시행령 | 누가 어떤 의무를 지는지 정하는 규범 | 적용 조항·시행일·운영 주체 해당 여부와 근거 |
| 고시·국가표준 | 안전조치나 접근성의 세부 기준 | 적용 검사항목과 실제 재현 증거 |
| 품질·관리체계 인증 | 별도 신청·심사 또는 일정 요건 충족 시 의무 | 기술 점검 결과와 인증 상태를 따로 기록 |
| 서비스 내부 규칙 | 자격증 발급 조건, 보유기간, 계약상 역할 | 확정 문서의 버전과 미결정 책임자 |

## 개인정보·정보보호 관련 법령 지도

법률과 시행령은 **처리 의무와 적용 대상**을, 개인정보보호위원회 고시는 **안전조치의 세부 기준**을 정한다. 아래는 자격증 발급 서비스에서 우선 대조할 항목이다. 실제 적용 여부는 운영 주체, 처리 규모, 본인확인기관·호스팅사와의 관계, 자격증별 별도 법령에 따라 판단한다.

**구분할 점:** 본인확인기관 제도가 있다고 이용 기관의 개인정보 처리 책임이 사라지지 않는다. 정보보호 관리체계 인증도 모든 사이트에 일괄 적용되는 의무가 아니다. 법령 링크는 **2026-10-25 확인 기준**이며, 구현·운영 판단에서는 해당 날짜 시행 원문과 계약을 다시 확인한다.
