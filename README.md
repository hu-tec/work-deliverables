# 업무 산출물 저장소

화면에서 자료를 찾을 때는 [산출물 목록](index.html)을, 소스 폴더를 찾을 때는 아래 네 가지 용도 구분을 사용합니다. [폴더 구조 화면](PROJECT_STRUCTURE.html)에서도 같은 구분을 볼 수 있습니다.

산출물 목록은 **실제 자료가 있는 소분류별 폴더 경로와 경로 복사 버튼**을 보여줍니다. 예를 들어 HTML의 `디자인관련 → 디자인시스템 본편`에서 디자인시스템 폴더를 확인할 수 있습니다. 포괄적인 대분류의 상위 폴더 경로는 표시하지 않습니다. 랜딩 ver1·ver2는 각 버전의 경로를 따로 표시합니다. 목록에는 저장소 기준 상대 경로를 간결하게 보여주고, 로컬 `index.html`에서 ‘전체 경로 복사’를 누르면 Windows 전체 경로가 복사됩니다. 파일을 선택하면 오른쪽에서도 그 파일의 전체 폴더 경로를 확인할 수 있습니다. 복사한 경로를 Windows 파일 탐색기의 주소창에 붙여 넣으면 해당 폴더로 이동합니다. HTML·Markdown·DB 목록의 파일별 다운로드 버튼은 경로 복사 버튼과 별도로 제공합니다.

```text
work-deliverables/
├── 01_화면_디자인/       디자인시스템, 랜딩페이지, UI·신청서 시안
├── 02_분석_기획/         시험·교육·업무 분석, 서비스 기획, DB 자료
├── 03_프로젝트_도구/     실행 가능한 프로젝트와 내부 도구
├── 04_작업_가이드/       AI 요청·Codex·인수인계 문서, 옛 구조 기록
├── downloads/           생성 시점의 다운로드 ZIP
├── scripts/             목록·날짜·자료 생성 스크립트
├── index.html           공개 산출물 목록
└── analyze.html         분석 자료 화면
```

## 랜딩페이지의 실제 위치

[교육·시험·협회 버전 표](01_화면_디자인/랜딩페이지/랜딩페이지3종/README.md)를 확인하세요. `랜딩페이지3종/` 바로 아래에는 `ver1/`과 `ver2/`만 있습니다. 새 페이지와 링크에는 실제 버전 경로를 사용합니다.

## 루트 파일

- `index.html`, `analyze.html`: 사이트 화면.
- `db-files.js`, `file-dates.js`, `handover-source-data.js`, `reference-links.js`: 화면에서 사용하는 자료·날짜·연결 정보.
- `AGENTS.md`: 저장소 작업 규칙. `PUSH_WORKFLOW.md`: 배포 절차.
- `PROJECT_STRUCTURE.html`: 현재 폴더 구조를 보는 화면.
- [기존 구조 분석 기록](04_작업_가이드/기존_구조_기록/): 이전 폴더명을 확인할 때만 사용.

`downloads/`의 ZIP은 생성 당시 묶음입니다. 현재 소스의 내용·경로와 다를 수 있으므로 신규 작업과 원본 대조에는 위 용도별 폴더의 실제 파일을 사용합니다. 이동 내역은 [폴더 이동 대조표](04_작업_가이드/폴더_이동_대조표.md)에 기록합니다.
