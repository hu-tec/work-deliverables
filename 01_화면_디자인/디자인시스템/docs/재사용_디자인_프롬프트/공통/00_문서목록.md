# 공통 재사용 디자인 프롬프트 문서목록

이 폴더는 사용자 화면, 관리자 화면, DB 화면, 카드형 화면, 표형 화면 어디에서나 재사용할 수 있는 공통 설계 기준이다.

기존 `사용자/`, `관리자/` 문서보다 더 앞에서 읽는 상위 기준이며, 구체 화면을 만들 때는 이 공통 기준을 먼저 적용한 뒤 화면 성격에 맞는 세부 문서를 함께 본다.

## 전체/공통 최우선 기준

- 생성일: 2026-07-02
- 적용 범위: 사용자 화면, 관리자 화면, DB 화면, 카드형 화면, 표형 화면, 검색/테이블/상세보기 화면 전체
- 우선순위: 사용자의 최신 지시 다음으로 이 `공통/` 폴더 기준을 먼저 적용한다.
- 목적: 새 화면을 만들 때 AI가 같은 밀도, 같은 배치 원칙, 같은 검수 순서로 작업하게 만드는 재사용 기준이다.

## 적용 우선순위

1. 현재 작업 중인 화면에서 사용자가 가장 최근에 확정한 지시
2. 이 `공통/` 폴더의 최신 기준
3. `관리자/` 또는 `사용자/` 폴더의 화면별 기준
4. 오래된 이미지 분석, 이전 시안, 예전 문서

접근성 점검 페이지는 예외다. `01_화면_디자인/디자인시스템/accessibility_check.html`과 `.a11y-*` 관련 크기, 간격, line-height, layout dimension은 줄이거나 고치지 않는다.

## 사용 순서

1. 새 화면이나 새 작업을 시작하기 전에 `00`, `01`, `03`, `04`, `10`을 먼저 본다.
2. 상단 메뉴, 탭, 헤더가 있으면 `02`를 적용한다.
3. 카드형 또는 표형 판단이 필요하면 `05`, `06`을 적용한다.
4. 검색/필터/입력이 있으면 `08`을 적용한다.
5. 행 클릭 상세 또는 우측 패널이 있으면 `09`를 적용한다.
6. 검색조건, 테이블, 상세보기가 함께 있으면 `11`을 최우선으로 적용한다.

## 공통 작성 방식

- 문서는 대분류, 중분류, 소분류 순서로 작성한다.
- 짧은 옵션, 상태, 필터, 버튼은 세로로 길게 나열하지 말고 가로로 묶는다.
- 긴 설명, 절차, 예외, 체크리스트는 세로로 둔다.
- 마지막에는 요약표를 둔다.
- 사용자가 말한 "촘촘하게"는 글자만 작게 만드는 뜻이 아니다. 정보 그룹, 행 높이, 빈 공간, 반복 제목, 줄바꿈까지 함께 줄이는 뜻이다.
