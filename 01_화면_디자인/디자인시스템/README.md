# 휴텍씨 디자인시스템 작업물

최종 정리일: 2026-07-03

소분류:
- 공통 00-11 문서는 2026-07-02에 만든 전체 우선 기준이다.
- 검색조건·테이블·상세가 함께 있으면 공통 11번을 최우선으로 본다.

## 3. 대분류: 핵심 화면 원칙

### 3.1 중분류: 검색과 테이블

소분류:
- 검색조건은 4-5단을 기본으로 하고 한 단 안에 짧은 조건을 다시 묶는다.
- 조건명과 옵션은 `회원유형 : 전체 일반회원 정식회원 기업회원 전문가`처럼 한 줄에 둔다.
- 선택된 필터는 별도 행이 아니라 검색어 앞에서 유동 배치한다.
- 상세가 닫히면 테이블이 전체 폭을 사용하고, 열리면 핵심 열과 상세가 함께 보인다.

### 3.2 중분류: 회원 상세

소분류:
- A 회원 기본정보와 B 상담 운영정보를 동시에 읽을 수 있게 한다.
- 상세 헤더를 반복하는 두 번째 진한 제목바를 만들지 않는다.
- 내부 진한 바는 저장, 상담이력, 전환, 실패 같은 작업 액션에만 사용한다.
- C 납부·회계 날짜 입력은 달력 선택이 가능해야 한다.

### 3.3 중분류: 보호 영역

소분류:
- `accessibility_check.html`의 크기와 배치를 변경하지 않는다.
- `layout.css`의 `.a11y-*` 유효 크기, 간격, line-height를 변경하지 않는다.
- 다른 디자인시스템 문서를 촘촘하게 만들어도 접근성 예시는 그대로 유지한다.

## 4. 대분류: 확인 방법

브라우저에서 `index.html`을 열고 BO/DB 메뉴에서 실물 테이블 화면을 확인한다. 원문 기준은 `docs/재사용_디자인_프롬프트/00_문서목록.md`에서 시작한다.
