타이포그래피 글자크기 기준

1. 대분류: 화면 성격별 글자 크기

1.1 중분류: 사용자 화면

사용자 화면은 읽기와 이해가 목적이므로 관리자 테이블보다 글자를 크게 둔다.

소분류:

  • 본문: 읽기 편한 크기
  • 카드 제목: 본문보다 한 단계 크게
  • 버튼: 클릭 가능한 크기와 padding 유지
  • 안내 문장: 지나치게 작게 줄이지 않음

1.2 중분류: 관리자/BO 화면

관리자 화면은 정보 비교와 반복 작업이 목적이므로 더 조밀한 크기를 사용할 수 있다.

소분류:

  • 대량 테이블 본문: 8px 기준 가능
  • 테이블 제목셀: 10px 기준 가능
  • 필터 label, checkbox label, badge: 8px 기준 가능
  • 상세 패널의 중요 제목: 10-12px 범위

1.3 중분류: 접근성 예외

접근성 점검 페이지는 글자 크기, line-height, control size를 줄이지 않는다.

2. 대분류: 제목 단계

2.1 중분류: 화면 제목

소분류:

  • 화면 전체 제목은 명확한 업무명으로 쓴다.
  • hero급 크기는 사용자 랜딩이나 소개 화면에만 제한적으로 쓴다.
  • 관리자 패널 안 제목은 작고 단단하게 둔다.

2.2 중분류: 패널 제목

소분류:

  • 패널 제목은 10-12px도 가능하다.
  • 작은 패널 안에 큰 H1처럼 보이는 제목을 쓰지 않는다.
  • 제목 아래 설명이 반복되면 제거한다.

2.3 중분류: label/value

소분류:

  • label은 짧고 고정된 폭으로 둔다.
  • value는 한 줄 표시를 우선한다.
  • 긴 값은 ellipsis 또는 상세에서 확인하게 한다.
  • 같은 행에 label과 value를 붙여 세로 공간을 줄인다.

예시:

회원유형 : 전체 일반회원 정식회원 기업회원 전문가
성별 : 전체 M F
가입일 : 25-02-04 / 홈페이지

3. 대분류: line-height와 letter spacing

3.1 중분류: 촘촘한 업무 화면

소분류:

  • line-height는 글자가 겹치지 않는 선에서 줄인다.
  • 원본 화면이 고정 px line-height와 좁은 letter spacing을 쓴다면 비슷한 밀도를 유지한다.
  • 글자 크기를 키울 때는 주변 padding과 row gap도 함께 확인한다.

3.2 중분류: 읽기 화면

소분류:

  • 긴 본문은 line-height를 충분히 둔다.
  • 문단 폭이 너무 넓으면 max-width를 둔다.

4. 대분류: 글자 크기 조정 원칙

4.1 중분류: 1단계만 키우기

사용자가 "글자 사이즈 1개씩만 키워줘"라고 말하면 전체 비율을 바꾸지 않고 해당 범위의 font-size만 한 단계 올린다.

소분류:

  • 범위를 먼저 확인한다.
  • 해당 범위 밖 글자는 바꾸지 않는다.
  • 크기만 키워서 줄바꿈이 생기면 grid 폭 또는 gap을 함께 점검한다.

4.2 중분류: 버튼과 입력의 글자

소분류:

  • 버튼 안 글자가 넘치면 width, min-width, white-space를 함께 조정한다.
  • 입력 label은 한 줄로 유지한다.
  • 너무 긴 버튼 텍스트는 짧은 동사로 바꾼다.

5. 요약표

항목기준
사용자 화면읽기 편한 크기 우선
BO 테이블본문 8px, 제목셀 10px 가능
패널 제목작고 단단하게
label/value한 줄 우선
크기 변경지정 범위만 1단계 조정
금지접근성 점검 페이지 크기 변경
